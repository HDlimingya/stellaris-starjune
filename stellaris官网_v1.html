CIVILIZATION LOOP / 资源循环链路

从一块石头，到一颗点燃核心的星核部件。 七步走完一次完整的文明回响。

副本不是终点，生产也不是孤立玩法。

玩家在生态舱生产的每一种基础资源，都可以转化为 STELLARIS 的修复进度；而主舰每一次跃迁式的状态跃迁，又会反向开放新的裂隙与新的生态舱模块。两者形成的回响，构成整个服务器的核心体验。

HABITAT SYSTEM / 生态舱系统

生态舱首先是一台生存设备，然后才逐渐成为家园。 四个模块，定义一台生态舱能成长成什么样。

// HABITAT — STANDARD

中央核心塔 + 环形生产平台

标准生态舱的轮廓公式：中央核心塔、环形生产平台、四向接口、外围隔离场节点。成长表现为平台扩大、生命区增加、管线由临时连接变为稳定模块。

MODULE 01

Isolation Field

隔离场扩展模块

扩大可建设范围，舱体边界由断续警戒变为稳定隔离场。

MODULE 02

Eco Cycle

生态循环模块

提升农业与生物系统能力，让生态舱从"活下去"迈向"长期可持续"。

MODULE 03

Refabricator

物质重构模块

增加可生成资源种类，是从 Mk.I 走向 Mk.III 的关键。

MODULE 04

Logistics

物流存储模块

提升管理便利性，让自动化与中后期多生态舱协作成为可能。

CORE RULE / 设计原则

不以纯粹清怪作为全部目标，每次进入都必须有明确任务。

首领需要可识别的技能预兆，原住民不应全部作为敌人，核心奖励必须服务生态舱或公共进度。

奖励去向 生态舱 / 公共进度
VISUAL SYSTEM / 视觉规范

高级感来自结构、比例、留白和功能秩序，不是粒子数量。 配色锁死，功能即美术，克制即高级。

锁定的色板

一个空间只保留一个主识别色；红橙警报色占比必须很低；粒子只用于状态变化，不成为环境常态。所有配比都写在本项目的视觉与品牌规范 v2 中。

  • 01

    方块可信

    所有建筑和设备先满足 Minecraft 的体素逻辑，再追求电影感。AI 概念图中的圆滑表面必须转译为可搭建的方块模块。

  • 02

    功能即美术

    每种颜色、灯光和材质都承担明确含义。青蓝是秩序，绿是生命，紫是裂隙与未知，金是遗物，橙是注意，红只在异常状态短时出现。

  • 03

    克制的高级感

    大面保持干净，细节集中在设备、接口和维护区。一个空间只保留一个主要视觉焦点，红橙警报色占比必须很低。

  • 04

    可见的文明重建

    世界必须随着公共进度发生变化：暗区恢复照明、断裂管线重新供能、机械臂重新运行、封锁舱门开启。公共进度必须产生可见变化，不能只是一条数字进度条。

ROADMAP / 开发路线

先让一条新手体验拥有完整且统一的视觉表达，再扩展整座主城。 MVP 范围严格控制，首版不为所有功能铺路。

PHASE 0

技术验证

核对服务端与插件版本，建立测试服，确认 SuperiorSkyblock2、BTDungeons、MythicMobs、CraftEngine、Citizens 等核心工具能稳定联动。确定玩家数据、全服进度与变量的唯一来源。

验收创建生态舱、副本进出、数据持久化均无管理介入
PHASE 1

核心闭环原型

标准生态舱、物质重构器 Mk.I / Mk.II、简化 STELLARIS、荒芜矿星灰盒副本、资源提交与文明进度。跑通"副本材料升级生态舱"完整闭环。

验收测试玩家无需解释即可完成生产—提交—远征—升级
PHASE 2

新手体验与世界观包装

冷冻苏醒流程、主城导航、NPC 与终端文案、统一术语、关键声音与粒子反馈、首次裂隙任务链。世界观通过空间与系统变化体现，不依赖 NPC 讲解。

验收新玩家 15 分钟内成功部署生态舱且理解三者关系
PHASE 3

首版内容扩展

繁茂菌星、机械遗迹、四类生态舱模块、日常与周期委托、排行榜与文明档案、第一个完整文明工程、基础经济调优。从 MVP 扩展到可持续游玩的首个公开版本。

验收三个裂隙拥有不同目标和奖励，不存在明显无限产出
PHASE 4

测试与上线准备

封闭测试、新玩家路径观察、经济和掉落调整、多人并发与副本压力测试、权限与漏洞测试、数据备份恢复演练、上线公告与帮助文档。

验收核心流程无阻断缺陷，关键数据可备份恢复
