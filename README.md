# 代号：星郡 · STELLARIS

一个 Minecraft 原创生存服务器 **「星郡」** 的官方形象展示站(单文件站点)与配套设定资料。

> 星舰文明重启 · 深空生存重建 —— 方块可信、功能即美术、克制的高级感。

---

## 打开方式

`stellaris官网_v2.html` 是**唯一现行版本**(单文件,含全部 CSS/JS)。下载整仓后:

- **直接双击** `stellaris官网_v2.html` 即可在浏览器打开(图片 `img/`、音乐 `audio/` 已做相对路径引用);
- 或在项目根目录起一个静态服务以获得最佳体验:

```bash
# Python 3
python -m http.server 8000
# 然后浏览器访问 http://localhost:8000/stellaris官网_v2.html
```

> ⚠️ 网页默认**不会自动播放音乐**——点击页面右下角圆形音乐按钮打开播放器,再点 ▶ 即可播放太空电梯主题背景乐。

---

## 功能一览

- **三视图单页应用**:主页 HOME / 世界观 WIKI / 设定图鉴 CODEX,顶栏与滚动无缝切换
- **世界观 Wiki**:内嵌完整 13 章节设定,左侧分组导航 + 阅读进度条 + 滚动同步高亮
- **设定图鉴**:19 张档案卡,分 SPACE / RESOURCE / FACTION / SYSTEM 四类 + 稀有度
- **深空粒子特效**:星空 + 流星 + 星云,按钮可开关(◈)
- **真实音乐播放器**:2 首太空电梯主题乐,play / 暂停 / 切歌 / 进度 / 音量全可用
- **移动端适配**:汉堡抽屉导航 + Wiki 章节 chips,390px 以下不溢出
